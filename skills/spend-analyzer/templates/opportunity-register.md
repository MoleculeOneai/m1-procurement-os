## Opportunity Type Key

| Type | Description |
|---|---|
| consolidation | Reduce number of suppliers in a category to leverage volume |
| price_variance | Same goods/services bought at different prices — standardise to best rate |
| maverick_spend | Spend outside contracted channels — route to preferred suppliers |
| tail_spend | Rationalise low-value supplier relationships |
| demand_management | Reduce consumption or eliminate non-essential spend |
| benchmark_gap | Current pricing is above market rate — renegotiate or go to market |
| contract_renewal | Contract approaching expiry — re-tender before auto-renewal |
